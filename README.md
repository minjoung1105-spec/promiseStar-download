# 약속별 (PromiseStar) 다운로드

아이가 스스로 해낸 일에 짧은 영상 시간을 선물하고,
시간이 끝나면 **아이가 직접 영상을 끄는 연습**을 돕는 부모용 안드로이드 앱이에요.

## 설치하기

1. 오른쪽 **Releases**에서 최신 버전의 `promise-star-x.y.z.apk`를 받으세요.
2. 받은 파일을 눌러 설치하세요. 처음이면 "출처를 알 수 없는 앱 설치"를 허용해야 해요.
3. 처음 약속을 누를 때 **다른 앱 위에 표시**와 **알림** 권한을 허용해 주세요.

- 부모 PIN 기본값: `1234` (설정에서 바꿀 수 있어요)
- Android 태블릿·휴대폰 지원
